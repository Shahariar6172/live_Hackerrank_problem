## Language

## How to Run

Make sure the Java Development Kit (JDK) is installed. Open a terminal in the solution’s directory, then run:

```bash
javac ProblemName.java
java ProblemName
```

Replace `ProblemName` with the class name in your solution. For example, if the file is `Solution.java` and the class is `Solution`, use:

```bash
javac Solution.java
java Solution
```

Provide the input required by the problem when the program runs.
